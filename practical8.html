# Practical No.: 8

Aim: Text Editing using Nano Editor: Create and edit files using Nano editor.

Theory: The Nano editor is a simple, user-friendly text editor in Linux used to create, edit, search and save text files.

Requirements:

- Linux (Ubuntu terminal)
- Nano Editor
- Basic knowledge of Nano shortcut keys.

a] Open and create a file using Nano

`$ nano student.txt` – Creates a new file named `student.txt` or opens it if it already exists.

b] Edit text and save the files

- `Ctrl + O` – Saves the edited file.
- `Ctrl + X` – Exits the Nano editor.

c] Search and replace text

- `Ctrl + W` – Search for a particular word or text in the file.
- `Ctrl + \` – Search for a word and replace it with another word.

d] Compare Nano and Vi editors (Advantages and Differences)

| Nano                                | Vi                                 |
| ----------------------------------- | ---------------------------------- |
| Easy for beginners                  | Takes more practice                |
| Commands are shown at the bottom    | Commands are mainly shortcut-based |
| No separate modes for basic editing | Has Insert and Command modes       |
| Simple editing and saving           | Powerful editing features          |
| Best for quick text editing         | Better for advanced text editing   |
