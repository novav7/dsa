Practical 12: Apache Web Server Installation and Virtual Hosting
Aim
Install Apache, deploy a test website, configure name-based virtual hosting, and verify HTTP/HTTPS concepts.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
Apache HTTP Server serves web content. A virtual host allows multiple websites to share one server by matching
hostnames. Ubuntu stores site definitions in /etc/apache2/sites-available and enables them through a2ensite.
