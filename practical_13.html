Practical Content

Procedure
1. Install Apache.
2. Create a document root and test page.
3. Create a virtual-host configuration.
4. Enable the site and disable the default if desired.
5. Test syntax and reload Apache.
6. Optionally enable SSL for a controlled lab certificate exercise.
Important Commands / Configuration
sudo apt-get install apache2
sudo mkdir -p /var/www/site1
printf '<h1>Site 1 - Linux Lab</h1>
' | sudo tee /var/www/site1/index.html
# /etc/apache2/sites-available/site1.conf
<VirtualHost *:80>
ServerName site1.lab.example
DocumentRoot /var/www/site1
ErrorLog ${APACHE_LOG_DIR}/site1-error.log
CustomLog ${APACHE_LOG_DIR}/site1-access.log combined
</VirtualHost>
sudo a2ensite site1.conf
sudo apache2ctl configtest
sudo systemctl reload apache2
curl -I http://site1.lab.example
# SSL module (certificate configuration required separately)
sudo a2enmod ssl
Verification
1. apache2ctl configtest should report Syntax OK.
2. Open the site from a client using its DNS name.
3. Inspect access/error logs.
Observations / Precautions

HTTPS requires a certificate and port 443 configuration; do not treat enabling the ssl module alone as complete
HTTPS setup.
Practical 13: FTP Server Configuration (vsftpd)
Aim
Install vsftpd and configure authenticated file transfer with local-user restrictions for a laboratory environment.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
