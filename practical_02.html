Practical 2: Static IP Configuration and Network Setup
Aim
Configure a static IPv4 address, verify connectivity, inspect routes and DNS settings, and optionally disable IPv6 in the
lab.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
Ubuntu 16.04 commonly uses /etc/network/interfaces with ifupdown. A static configuration defines address, netmask,
gateway, and DNS servers. Interface names may be eth0 or predictable names such as ens33 depending on the
VM/hardware.
Procedure
1. Identify the interface name.
2. Back up /etc/network/interfaces.
3. Configure the assigned static IPv4 values.
4. Restart networking or reboot the lab VM.
5. Verify address, route, DNS resolution, and reachability.
6. Disable IPv6 only if the exercise requires it.
Important Commands / Configuration
ip link
ip addr
sudo cp /etc/network/interfaces /etc/network/interfaces.bak
# Example /etc/network/interfaces
auto ens33
iface ens33 inet static
address 192.168.10.10
netmask 255.255.255.0
gateway 192.168.10.1
dns-nameservers 192.168.10.10 8.8.8.8
sudo systemctl restart networking
ip addr show ens33
ip route
ping -c 4 192.168.10.1
getent hosts ubuntu.com
# Optional IPv6 disable via /etc/sysctl.conf
net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
sudo sysctl -p
Verification
1. Confirm the expected IPv4 address with ip addr.
2. Confirm the default route with ip route.
