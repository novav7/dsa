Practical No.: 7

Aim: Text Editing using Vi Editor: Create and edit files using Vi editor.

Requirement: WSL

a] Open and create file using `vi`

1] `vi myfile.txt` – Opens an existing file for editing. If the file does not exist, it creates a new file.

b] Work in Insert Mode and Command Mode

1] `i` – Enters Insert mode to type or edit text.

2] `Esc` – Exits Insert mode and returns to Command mode.

3] `h/j/k/l` – Moves the cursor left, down, up, and right respectively.

c] Save & exit file (`:w`, `:q`, `:wq`)

1] `:w` – Saves the file.

2] `:q` – Quits the Vi editor.

3] `:wq` – Saves the file and quits the Vi editor.

d] Edit & delete text using basic Vi commands

1] `x` – Deletes the character under the cursor.

2] `dw` – Deletes a word from the cursor position.

3] `dd` – Deletes the current line.

4] `u` – Undoes the last change.

5] `yy` – Copies the current line.

6] `p` – Pastes the copied text.

7] `:/linux` – Searches for the word "linux" in the file.
