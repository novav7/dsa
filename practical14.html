# Practical No.: 4

Aim: Introduction to Shell Scripting: Create and execute shell scripts.

Theory: A shell script is a text file containing commands and executables in order. It starts with a shebang (`#!/bin/bash`) line specifying the path to the interpreter.

Requirements:

- Linux
- WSL Terminal

a] Create a script file using `vi` or `nano`

Write a simple script using echo statements.

`nano name.sh`

b] Make script executable using `chmod +x`

`chmod +x name.sh` – Text files lack execution permission. This command allows the file to run like a binary.

c] Execute script and observe output

`./name.sh` – Using `./` triggers the file execution from the current working directory, prompting the shell to read code.
