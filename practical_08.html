Practical 8: Process Management and System Monitoring
Aim
Monitor processes, change priorities, terminate test processes, and analyze CPU and memory usage.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
A process is a running program identified by a PID. Linux scheduling priority can be influenced using nice and renice.
Administrators use ps, top, free, uptime, and related tools to observe resource usage.
Procedure
1. Display processes.
2. Start a harmless background test process.
3. Find its PID.
4. Change its nice value.
5. Terminate it gracefully and, only if required, force termination.
6. Inspect CPU load and memory.
Important Commands / Configuration
ps aux | head
top
free -m
uptime
sleep 600 &
echo $!
ps -o pid,ppid,ni,stat,cmd -p $!
renice 10 -p $!
kill $!
# Force only when a process does not terminate normally:
# kill -9 PID
pgrep -a ssh
vmstat 1 5
Verification
1. Confirm the test process exists before renice.
2. Verify the NI value changed.
3. Confirm the process disappears after kill.
Observations / Precautions

Use SIGKILL (-9) only when normal termination fails because the process cannot clean up.
