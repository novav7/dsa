Practical No.: 3

1\. File Handling Operations: Create and manage files.

Requirement: WSL

a] Create files using `touch`

1] touch – Creates a new empty file, updates the timestamp of an existing file.

b] View file content using `cat`, `more`, `less`

1] cat – Displays the contents of a file in the terminal.

2] more – Displays a file's contents one screen at a time.

3] less – Displays a file's contents one screen at a time and allows scrolling in both directions.

c] Copy & move files using `cp`, `mv`

1] cp – Copies files or directories from one location to another.

2] mv – Moves or renames files & directories.

d] Delete file using `rm`

1] rm – Removes or deletes files & directories.
