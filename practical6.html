Practical No.: 6

Aim: Basic Shell Commands and Redirection: Use essential shell commands and output redirection.

Requirement: WSL

a] Display text & variables using `echo`

1] echo – Display text or the value of a variable in the terminal.

b] Use redirection operators `>`, `>>`

1] > – Redirects command output to a file, creating the file or overwriting its existing content.

2] >> – Redirects command output to a file and appends it to the existing content.

c] Use pipes (`|`) with commands like `ls`, `sort`

1] | – Sends the output of one command as the input to another command.

2] ls | sort – Lists files & directories and sorts the output alphabetically.

d] Count lines/words using `wc`

1] wc – Counts the number of lines, words and characters in the given input or file.

- wc -l – Counts the number of lines.
- wc -w – Counts the number of words.
- wc -c – Counts the number of characters/bytes.
