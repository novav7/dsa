Practical 1: Initial Server Setup and User Administration
Aim
Install Ubuntu Server 16.04 and perform basic user, group, sudo, password-policy, and authentication administration.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
Linux is a multi-user operating system. Local account details are recorded primarily in /etc/passwd, password hashes in
/etc/shadow, and group membership in /etc/group. sudo provides controlled administrative privileges without requiring
routine direct root login.
Procedure
1. Install Ubuntu Server and create the initial administrator during installation.
2. Update package metadata.
3. Create two laboratory users and a group.
4. Add users to the group and grant one user sudo privileges.
5. Set password aging rules and inspect authentication records.
Important Commands / Configuration
sudo apt-get update
sudo adduser student1
sudo adduser student2
sudo groupadd labusers
sudo usermod -aG labusers student1
sudo usermod -aG labusers student2
sudo usermod -aG sudo student1
id student1
groups student1
sudo chage -M 90 -m 1 -W 7 student1
sudo chage -l student1
getent passwd student1
sudo tail -n 30 /var/log/auth.log
Verification
1. Run su - student1 and verify login.
2. Run sudo -l as student1.
3. Verify group membership with id student1.
Observations / Precautions

Use strong lab passwords and never publish real credentials in the journal.

Use usermod -aG; omitting -a can replace supplementary groups.
