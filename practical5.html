Practical No.: 5

Aim: User & Group Management: Create and manage users & groups.

Requirement: WSL

a] Create a new user using `useradd` and set password using `passwd`

1] `sudo useradd` – Creates a new user account in the system.

2] `sudo passwd` – Sets or changes the password of a user.

3] `cat /etc/passwd` – Displays information about all users configured on the system.

b] Delete a user using `userdel`

1] `sudo userdel` – Deletes a user.

c] Create and delete groups using `groupadd`, `groupdel`

1] `sudo groupadd` – Creates a new group in the system.

2] `sudo groupdel` – Deletes an existing group from the system.

3] `cat /etc/group` – Displays information about all groups configured on the system.

d] Add user to group and verify using `id`

1] `sudo usermod -aG groupname username` – Adds the specified user to the specified group without removing the user from the existing groups.

2] `id username` – Displays the user ID (UID), group ID (GID), and groups associated with the specific user.
