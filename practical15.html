# Practical No.: 5

Aim: Variables, Control Statements, and Loops using Shell Scripting

Theory: Dynamic scripting requires storing configuration variables, evaluating conditions (`if-else`) and using iteration mechanisms (`for`, `while`) to handle repetitive tasks.

Requirements:

- Linux
- WSL Terminal

a] Declare and use variable in shell script

Accept user input using `read`.

```
nano name.sh
```

```
#!/bin/bash
echo "What is your name?"
read user_name
echo "Hello: $user_name, Nice to meet you!"
```

b] Use condition statement (if-else)

```
nano if_else.sh
```

```
#!/bin/bash
echo "Enter a number:"
read num

if [ $num -gt 0 ]
then
    echo "positive number"
else
    echo "Zero or negative number"
fi
```

```
chmod +x if_else.sh
./if_else.sh
```

c] Implement simple loop (for or while)

For Loop:

```
nano for_loop.sh
```

```
#!/bin/bash
for i in 1 2 3 4 5
do
    echo "Number: $i"
done
```

```
chmod +x for_loop.sh
./for_loop.sh
```

While Loop:

```
nano while_loop.sh
```

```
#!/bin/bash
count=1

while [ $count -le 5 ]
do
    echo $count
    count=$((count + 1))
done
```

```
chmod +x while_loop.sh
./while_loop.sh
```
