Practical 19: MySQL Server Installation and Web-based Administration
Aim
Install MySQL Server, create databases and users, apply least-privilege access, and administer the database with
phpMyAdmin.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
MySQL is a relational database server. Administrative tasks include secure initial configuration, database creation, user
creation, privilege assignment, backup, and controlled network/web administration. phpMyAdmin provides a browser
interface but must be protected carefully.
Procedure
1. Install MySQL.
2. Run the security setup.
3. Create a database and restricted user.
4. Create a sample table and insert data.
5. Install phpMyAdmin if required by the syllabus.
6. Verify login and database access.
Important Commands / Configuration
sudo apt-get install mysql-server
sudo mysql_secure_installation
mysql -u root -p
CREATE DATABASE college_db;
CREATE USER 'labuser'@'localhost' IDENTIFIED BY 'Use-A-Lab-Password';
