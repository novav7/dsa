Practical 17: LDAP Server Configuration and User Account Management
Aim
Install OpenLDAP, create directory entries for centralized users, and administer entries with command-line tools and
optionally phpLDAPadmin.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
LDAP is a directory protocol used to store structured identity and organizational information. OpenLDAP provides the
slapd server. Entries are identified by Distinguished Names (DNs) and described by object classes and attributes.
Procedure
1. Install slapd and ldap-utils.
2. Reconfigure the directory suffix for the lab if required.
3. Query the directory root.
4. Create an organizational unit and user LDIF.
5. Add entries with ldapadd.
6. Optionally install phpLDAPadmin for web-based educational administration.
Important Commands / Configuration
sudo apt-get install slapd ldap-utils
sudo dpkg-reconfigure slapd
ldapsearch -x -LLL -H ldap://localhost -b dc=lab,dc=example
# Example users.ldif
dn: ou=People,dc=lab,dc=example
objectClass: organizationalUnit
ou: People
dn: uid=student1,ou=People,dc=lab,dc=example
objectClass: inetOrgPerson
cn: Student One
sn: One
uid: student1
mail: student1@lab.example
ldapadd -x -D cn=admin,dc=lab,dc=example -W -f users.ldif
ldapsearch -x -LLL -b dc=lab,dc=example '(uid=student1)'
# Optional syllabus GUI
sudo apt-get install phpldapadmin
