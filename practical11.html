# Module – 2: Practical No. 1

Process Management Basics

Understand process creation and monitoring.

Theory:

A process is an active instance of a running program in Linux. Every process is tracked by the kernel via a unique integer called the Process ID (PID).

Process management allows users to view running applications and terminate frozen or unwanted tasks safely.

Requirements:

- Linux
- WSL Terminal

a] View running processes using `ps` and `top`

`$ ps aux` – Takes a static snapshot of all active processes on the system.

`$ top` – Launches an interactive, real-time interface displaying resource usage dynamically.

b] Identify Process ID (PID)

`$ pgrep firefox`

`$ ps aux | grep firefox` – Used to extract the unique PID of a running process needed to perform signals or threading.

c] Kill a process using `kill` command

`$ kill 1234` – Standard kill politely asks the process to exit, saving data.

d] Use `htop` for interactive process monitoring

`$ htop` – An interactive text-based visual sort, search and kill process cleanly using shortcut keys.
