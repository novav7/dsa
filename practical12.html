# Practical No.: 2

Aim: Foreground and Background Processes

Theory: Linux allows multitasking via running processes in the foreground (interactive) and background (non-interactive).

Requirements:

- Linux
- WSL Terminal

a] Run a process in the background using `&`

`$ sleep 100 &`

Appending an ampersand (`&`) at the end of a command instructs the shell to spawn the background job, allowing it to run in the background.

b] View background jobs using `jobs`

`$ jobs`

Lists active background jobs spawned in the current shell session.

c] Bring job to foreground using `fg`

`$ fg %1`

Moves background job 1 into active interactive foreground state.

d] Suspend and resume process

Press `Ctrl + Z` while a job is running in the foreground.
