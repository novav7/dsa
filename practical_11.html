Practical 11: Integration of DNS and DHCP Services
Aim
Integrate ISC DHCP and BIND9 so DHCP can securely update DNS records for dynamically assigned clients.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
Dynamic DNS (DDNS) allows DHCP to update DNS records as leases are assigned or released. Secure updates can use a
shared TSIG key. This is an advanced lab and should be performed on an isolated network.
Procedure
1. Generate a TSIG key.
2. Include the key in BIND and DHCP configurations.
3. Allow signed updates for the forward and reverse zones.
4. Enable interim DDNS in dhcpd.conf.
5. Restart both services.
6. Renew a client lease and verify forward/reverse records.
