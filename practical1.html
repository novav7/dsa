Practical No.: 1

1\. Introduction to Linux and Terminal Basics:

Understand basic Linux environment and command-line usage.

2\. Requirement: WSL

a] Open terminal and execute basic commands:

`whoami`, `date`, `cal`, `uname`

1] whoami – Displays the username of the currently logged-in user.

2] cal – Display the calendar for the current month.

3] uname – Display basic information about the operating system.

4] date – Display the current date and time.

b] Display current directory using `pwd`:

1] pwd – Display the path of the current working directory.

c] View logged-in user using `who`:

1] who – Displays information about users currently logged into the system.

d] Clear screen and exit terminal using `clear`, `exit`:

1] clear – Clears all the previous output from the terminal screen.

2] exit – Closes the current terminal session or exits the shell.
