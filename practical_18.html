Practical 18: NIS Server and Client Configuration
Aim
Configure NIS to share account information across a controlled laboratory network and bind an Ubuntu client to the NIS
domain.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
NIS is a legacy centralized account-information service. It is included because it appears in the syllabus, but it is not
recommended for modern untrusted or production networks due to weak security compared with LDAP/Kerberos-based
approaches.
Procedure
1. Install nis on server and client.
2. Set a lab NIS domain.
3. Configure the server as master.
4. Initialize NIS maps.
5. Configure client yp.conf.
6. Adjust NSS to consult NIS and test user lookup.
Important Commands / Configuration
sudo apt-get install nis
sudo domainname labnis
# /etc/defaultdomain
labnis
# Server: /etc/default/nis
NISSERVER=master
# Configure /etc/ypserv.securenets for the lab subnet, then initialize maps
sudo /usr/lib/yp/ypinit -m
sudo systemctl restart nis
# Client /etc/yp.conf
ypserver 192.168.10.10
# /etc/nsswitch.conf examples
