Practical 10: DHCP Server Configuration
Aim
Install ISC DHCP Server, define an address pool, and configure a fixed address reservation based on MAC address.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
DHCP automatically supplies IP configuration to clients. A scope/subnet declaration can specify address ranges, gateway,
DNS server, and lease times. A host reservation maps a known MAC address to a fixed IP.
Procedure
1. Install isc-dhcp-server.
2. Select the server interface.
3. Configure a subnet and dynamic range.
4. Add a host reservation.
5. Validate configuration and restart DHCP.
6. Set a client to obtain an address automatically.
Important Commands / Configuration
sudo apt-get install isc-dhcp-server
# /etc/default/isc-dhcp-server
INTERFACES="ens33"
# /etc/dhcp/dhcpd.conf
authoritative;
default-lease-time 600;
max-lease-time 7200;
subnet 192.168.10.0 netmask 255.255.255.0 {
