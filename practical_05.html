Practical 5: SSH Server Installation and Secure Remote Access
Aim
Install OpenSSH Server, configure password-based remote access in a controlled lab, and test Ubuntu/Windows client
login.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
SSH provides encrypted remote shell access. The server daemon is sshd and the Ubuntu package is openssh-server.
Password authentication is useful for introductory labs, though key-based authentication is preferred for modern
production deployments.
Procedure
1. Install OpenSSH Server.
2. Back up sshd_config.
3. Verify Port, PermitRootLogin, and PasswordAuthentication settings.
4. Restart SSH and verify syntax/status.
5. Connect from Linux and Windows clients.
Important Commands / Configuration
sudo apt-get update
sudo apt-get install openssh-server
sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak
# Relevant settings in /etc/ssh/sshd_config
Port 22
PermitRootLogin no
PasswordAuthentication yes
sudo /usr/sbin/sshd -t
sudo systemctl restart ssh
sudo systemctl status ssh
ss -tlnp | grep :22
# Linux client
ssh student1@192.168.10.10
# Windows PowerShell/OpenSSH client, if available
ssh student1@192.168.10.10
Verification
1. Confirm sshd configuration syntax returns no error.
2. Verify port 22 is listening.
3. Log in from a client and run hostname and whoami.
Observations / Precautions

Do not enable direct root SSH login.

For Internet-facing systems, prefer SSH keys and restrict password authentication.
