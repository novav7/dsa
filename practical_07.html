Practical 7: Disk Partitioning and File System Management
Aim
Create a disk partition, format it, mount it, configure persistent mounting, and inspect disk usage.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
Linux exposes disks as block devices such as /dev/sdb. A partition can be formatted with a filesystem such as ext4 and
mounted into the directory tree. /etc/fstab defines persistent mounts. UUID-based entries are safer than relying only on
device names.
Procedure
1. Attach a small virtual disk.
2. Identify the correct unused device.
3. Create a partition.
4. Format it as ext4.
5. Create a mount point and mount it.
6. Obtain UUID and add a persistent fstab entry.
7. Test fstab safely.
Important Commands / Configuration
lsblk
sudo fdisk /dev/sdb
# In fdisk: n -> p -> 1 -> defaults -> w
sudo mkfs.ext4 /dev/sdb1
sudo mkdir -p /data
sudo mount /dev/sdb1 /data
df -hT
sudo blkid /dev/sdb1
# Example /etc/fstab entry (use actual UUID)
UUID=YOUR-UUID-HERE /data ext4 defaults 0 2
sudo mount -a
df -hT /data
du -sh /data
Verification
1. Verify /data appears in df -hT.
2. Run sudo mount -a and ensure no error occurs.
3. Reboot only after mount -a succeeds, then verify persistent mounting.
Observations / Precautions

Selecting the wrong disk can destroy data. Confirm with lsblk before fdisk or mkfs.

Back up /etc/fstab before editing.
