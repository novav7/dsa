Practical 16: Samba Server Configuration for Windows–Linux File Sharing
Aim
Install Samba, create an authenticated share, and verify Windows–Linux file sharing.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
Samba implements SMB/CIFS services and enables interoperability with Windows clients. Linux users can be added to
the Samba password database and access can be controlled per share.
Procedure
1. Install Samba.
2. Create a shared directory and group.
3. Create/add a local user and Samba password.
4. Add a share definition.
5. Validate smb.conf.
6. Restart Samba and connect from Windows.
Important Commands / Configuration
sudo apt-get install samba
sudo groupadd sambashare
sudo mkdir -p /srv/samba/shared
sudo chgrp sambashare /srv/samba/shared
sudo chmod 2770 /srv/samba/shared
sudo usermod -aG sambashare student1
sudo smbpasswd -a student1
# Add to /etc/samba/smb.conf
[Shared]
path = /srv/samba/shared
browseable = yes
read only = no
valid users = @sambashare
create mask = 0660
directory mask = 2770
testparm
sudo systemctl restart smbd
smbclient -L //192.168.10.10 -U student1
# Windows Explorer path: \192.168.10.10\Shared
Verification
1. testparm should report a valid configuration.
2. Connect from Windows using the Samba user.
3. Create a test file and verify it on Linux.
