Practical No.: 4

Aim: File Permission and Ownership: Understand and modify file permissions.

a] View file permissions using `ls -l`

1] ls -l – Displays detailed information about files including their permissions, owner, group, size & modification date.

b] Change permissions using `chmod` (Symbolic Method)

1] chmod (symbolic method) – Change file permissions using symbols such as `u`, `g`, `o`, `+`, `-`.

Symbols:

- `u` = User (owner)
- `g` = Group
- `o` = Others
- `r` = Read
- `w` = Write
- `x` = Execute

c] Change permissions using `chmod` (Numeric Method)

1] chmod (numeric method) – Change file permissions using numeric values such as `755`, `644`, and `777`.

Numeric values:

- Read = 4
- Write = 2
- Execute = 1

d] Change ownership using `chown` and `chgrp`

1] sudo chown – Changes the ownership of a file or directory to a specified user.

2] sudo chgrp – Changes the group ownership of a file or directory to a specified group.
