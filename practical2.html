Practical No.: 2

1\. Linux File System Navigation: Perform directory navigation and listing operations.

Requirement: WSL

a] List files using `ls`, `ls -l`, `ls -a`

1\) ls – List files and directories in the current directory.

2\) ls -l – List files and directories with detailed information.

3\) ls -a – List all files and directories, including hidden files.

b] Change directories using `cd` (absolute & relative paths)

1] cd (absolute path) – Changes to a directory by specifying its complete path from the root directory.

2] cd (relative path) – Changes to a directory by specifying its path relative to the current directory.

c] Create directories using `mkdir`

1] mkdir – Creates a new directory.

d] Remove directories using `rmdir`

1] rmdir – Removes an empty directory.
