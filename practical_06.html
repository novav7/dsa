Practical 6: NTP Server and Client Configuration
Aim
Configure NTP time synchronization and use the Ubuntu host as an NTP server for laboratory clients.
Requirements
Ubuntu Server 16.04 LTS virtual machine or lab server, sudo-enabled administrator account, and a client VM where
required. Take a VM snapshot before changing network, firewall, authentication, disk, or directory-service settings.
Theory
NTP synchronizes clocks over a network. Accurate time is important for logs, authentication, certificates, databases, and
distributed services. Ubuntu 16.04 can use the ntp package for this syllabus exercise.
Procedure
1. Install ntp.
2. Back up ntp.conf.
3. Define upstream servers and allow the lab subnet to query the server.
4. Restart NTP.
5. Configure an Ubuntu client to use the server.
6. On Windows, point the Windows Time service to the lab NTP server if permitted.
Important Commands / Configuration
sudo apt-get install ntp
sudo cp /etc/ntp.conf /etc/ntp.conf.bak
# Add/adjust in /etc/ntp.conf
server 0.ubuntu.pool.ntp.org iburst
server 1.ubuntu.pool.ntp.org iburst
restrict 192.168.10.0 mask 255.255.255.0 nomodify notrap
sudo systemctl restart ntp
ntpq -p
# Ubuntu client: set server line to
server 192.168.10.10 iburst
sudo systemctl restart ntp
ntpq -p
# Windows command prompt as administrator (lab client)
w32tm /config /manualpeerlist:"192.168.10.10" /syncfromflags:manual /update
w32tm /resync
w32tm /query /status
Verification
1. Run ntpq -p on server and client.
2. Compare date output on both hosts.
3. On Windows, query time service status.
Observations / Precautions

Allow UDP port 123 through the firewall if clients cannot synchronize.
